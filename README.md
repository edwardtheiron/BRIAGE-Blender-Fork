# BRIAGE-Fork

Independent compatibility fork of the BRIAGE Blender add-on for
Train Simulator Classic.

## About

BRIAGE is a Blender add-on for importing and exporting assets used by
DTG Train Simulator Classic.

This repository contains an independently maintained fork of the
original BRIAGE project.

The original BRIAGE releases are preserved in the `original/`
directory for reference and historical provenance.

## Current version

**BRIAGE-Fork 3.3.102**

**Supported Blender version: 4.2.x**

This version is based on the original BRIAGE 3.3.101 release for
Blender 4.1.

The fork restores compatibility with Blender 4.2 and fixes issues
encountered during actual use of the add-on.

## Installation

1. Download the latest `BRIAGE-Fork` release.
2. In Blender, open **Edit → Preferences → Add-ons**.
3. Select **Install...**
4. Select the BRIAGE-Fork ZIP archive.
5. Enable the add-on.

## Development status

This is an independently maintained compatibility fork.

Blender 4.2 is the currently tested target version.

Compatibility with other Blender versions has not been established
unless explicitly stated in a release.
